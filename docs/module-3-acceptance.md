# 模块三验收：统一与切换字体

1. 外观 → 字体，依次选系统默认、思源黑体、霞鹜文楷、思源宋体（按用户确认替代 MiSans）。预期全 App 立即切换。
2. 依次打开今日、聊天、记忆、关于星回、设置和编辑弹窗。标题 20、正文 15、辅助 13，行高 1.5、字重一致，数值均来自 theme.yaml。
3. 完全退出重开。预期字体选择保留。
4. 断网再切换三款内置字体。预期正常显示，运行时不会下载字体。

内置字体来自 google/fonts 的固定提交，Git blob 校验通过，OFL 许可证随资产提供。用 google_fonts 加载本地字体。思源系列使用 Noto SC 家族，霞鹜文楷使用开源 TC 家族。
