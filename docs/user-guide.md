# 星辉 Windows 使用说明

使用本次模块一 Windows ZIP，完整解压，双击 `start_backend.bat` 后打开 App。设置 → “连接本地后端”；令牌自动从本机文件读取。

聊天保存、已确认记忆、学习与打卡均依赖本机后端 SQLite；App 的外观、背景和连接设置保存在本机设备存储。没有连接时规则聊天不跨会话保存。

记忆页“他记得的事”可以添加、编辑、删除。聊天输入“记住这件事：我喜欢星空”会明确保存。相处学习候选仍需审核后才能进入长期记忆。勾选“本轮不保存”或关闭设置的聊天保存，可停止保存聊天。

双击启用/取消登录自启 bat 管理当前用户启动项；保持解压路径固定。后端子进程崩溃时启动器自动恢复。

[完整验收步骤、数据位置和故障处理](module-1-acceptance.md)。本版是规则回复；正式人设静态台词、模型接入、完整 Android、图库、饮食运动、通知和备份按后续模块验收。


## Windows 新功能

热量追踪含饮食/运动两页签，不依赖后端，用 get_storage 每日记录。食品1838条来自 jhyan-ux 指定仓库，缺失值不估算；运动1111条来自2024官方表的公开镜像。设置填写体重、基础代谢、活动系数（默认1.2）；目标=BMR×活动系数，缺口=目标−摄入+运动消耗。

每日提醒在设置配置，Windows原生排队+每日本地计划任务补排；关闭五类即可取消任务。完整Android仍后置。设置提供全量JSON备份与恢复，包含后台聊天/记忆/打卡、热量、外观、提醒和自定义背景；凭据不导出。备份后才清空数据，恢复需要连接本地后端。
