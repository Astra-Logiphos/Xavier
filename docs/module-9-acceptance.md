# 模块九验收：一键备份与恢复

1. 双击 start_backend.bat 并连接，首次成功连接提示“建议每周备份一次”。在聊天、记忆、学习打卡、饮食运动各创建一条，选择字体/背景，设一项提醒。
2. 设置→一键备份全部数据→选择自己目录，预期产生 xinghui-backup-时间戳.json。包含数据库全部记录与设置、每日热量与个人参数、外观、提醒、导入背景图片及缩略图；不含 AUTH_TOKEN 或模型 Key。
3. 检查备份文件已保存，再设置→删除全部个人数据→确认。预期个人记录、热量与外观/提醒清空，应用访问令牌保留以便恢复；系统补排任务取消。
4. 从 JSON 恢复全部数据→选择备份→确认替换。预期聊天、他记得的事、打卡、每日热量、体重目标、字体背景和提醒重新出现；重启复查。
5. 非星辉文件/重复 ID/缺少有效人设引用会被拒绝，数据库不被部分覆盖。数据库导入使用 SQLite 事务；客户端恢复失败尝试回滚到恢复前数据，后台中途断电仍需用原始备份重试。

照片只复制到应用文档目录，不覆写原相册。JSON 是个人明文备份，请保管在自己的本机目录。恢复没有执行脚本、加载 pickle、传出数据或写入模型凭据。
