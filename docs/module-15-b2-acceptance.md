# 模块十五批次二：性能、头像、一键启动

前置：m15-b1 ·1757908；原始底座666e2e2；分支codex/m15。只交付增量。

## 方案摘要

输入上屏保持即时；300ms只合并草稿处理，不阻塞发送。消息列表缓存与稳定key隔离输入及忙碌状态。健康检查改为/health，2/4/8/16/30秒退避，窗口隐藏暂停；/status业务数据仅启动、发消息后、切页/窗口返回时刷新。记忆索引缓存300秒；编辑/删除/撤销同意/清空/恢复立即失效，排序脱离整请求锁，生成与保存门禁保持。

theme.yaml仅新增performance参数，已有全部主题色、背景定义原样保留；高/中/低粒子分别原数量50%/25%/0，低档关粒子及模糊。设置持久化。参考目录无图片，对齐既有分边、外侧圆形头像、时间分组、圆润蓝紫皮肤；不采用微信绿气泡、灰底或方形头像。

头像复用file_picker和image库，等比压至长边512、JPEG质量80，安装目录config/avatars/独立副本；不保存原路径。恢复默认重新使用bubbles.yaml的avatar.userPath。start_all.bat先验证带本机令牌的后端状态，未就绪绝不启动App。没有新增依赖；prompt未修改。

## 测试结果与前后对比

构建中；最终报告将在Windows验证完成后填入真实数字，未填项目不表示通过。Windows profile VM Service提供DevTools同源原始时间线；控制器输入到Flutter绘制提交时间不等同物理键盘到屏幕扫描延迟。真实智谱首字<3s无法在无Key工作区测量，待用户自测；当前非流式接口在完整回复返回后显示文字。

## 应用与回退

关闭App、本地后端及监督程序，完整解压m15-b2-patch.zip到新目录，运行其中apply_patch.bat并选择当前m15-b1安装目录；成功后双击安装目录start_all.bat。设置预期m15-b2 ·本批hash。ZIP内revert.bat仅回退本批；安装目录revert.bat回退当前最新批。后续批次覆盖同一文件时必须逆序回退，避免破坏补丁链；本批不删除旧备份。

## 用户事后实测

1. 外观→动效质量，高/中/低切换，重开保持；主题配色与背景无变化。
2. 设置→我的头像，选jpg/png；发送后我方头像显示。关闭App、删除原图、重开仍显示；恢复默认有效。
3. 关闭后端和App，双击start_all.bat，后端先就绪、App随后启动并显示本地已连接。端口被其他程序占用时应报错，App不提前打开。
