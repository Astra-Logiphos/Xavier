# 模块二验收：人设与静态台词

1. 完整解压本次 ZIP，启动 App。今日页在早上、中午和晚上展示不同问候；更改系统时间后等一分钟或重开 App，预期语气短句、慵懒，偶尔提及鸟、肉或杨桃。测试只用静态本地时间，不请求模型。
2. 今日 → 点击学习/情绪/陪伴打卡。预期成功提示是角色语气，如“嗯，今天的努力，我看见了。先休息一会儿。”；网络失败时不显示成功鼓励。
3. 关于星回 → 查看基础档案、外貌、性格、喜好、怪癖、台词和禁忌。情绪与相处完整列出报告 3.5 的九个场景。
4. 未启动后端也能显示人设、问候和静态台词。聊天持久化仍需模块一的本地后端。
5. 本模块存放 GLM-4-Flash system prompt 模板，但未调用模型；静态应用台词与官方原句区分，来源报告完整保留。

自动验证与 Windows 打包通过后继续模块三；用户电脑实机效果尚待你自行确认。
