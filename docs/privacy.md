# 本地数据与隐私

后端只监听本机回环地址。令牌、聊天、记忆、学习和打卡保存在使用者 Windows 用户目录，应用外观与背景也只保存在本机。令牌通过请求头发送，拒绝重定向，客户端拒绝远程后端地址。

启动器首次开启聊天保存，应用设置可随时关闭，之后启动器不会改变选择。“本轮不保存”及明确不记录命令优先；敏感内容规则有限，仍需自行决定保存什么。

长期记忆必须明确同意，相处学习候选必须审核。SQLite 尚未加密，请保护 Windows 账号。个人导出不要提交到 GitHub；删除当前数据库记录不会删除手动备份。

真实模型调用默认关闭。未来若显式启用，输入和相关已同意记忆会发送给模型供应商，需要确认其隐私与计费政策。本模块没有验证真实模型。

语音朗读默认关闭。系统 TTS 完全离线；若启用"使用云端音色"（edge-tts，非官方接口），合成文本会发送至微软服务，关闭该开关或关闭"语音朗读"即可随时切回纯本地，已合成音频仅缓存在本机 runtime/tts_cache。

聊天记录导出（设置页）仅含对话文本与时间戳，不含系统提示词、人设内部字段或令牌；文件保存在你选择的位置，请自行妥善保管。
