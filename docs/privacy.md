# 隐私与安全边界

默认模型 API/付费/外部搜索/真实语音关闭、聊天记录关闭。Key 从后端环境变量读，客户端没有供应商 Key。AUTH_TOKEN 是应用授权令牌，客户端安全存储；单用户 token 持有者能查看/删除全部数据，不能多人共享。
请求正文与请求路径不写日志，供应商错误正文隐藏；健康接口不输出密钥。WSGI 请求上限 64 KiB、模型响应上限 1 MiB、客户端拒绝非 HTTPS 地址和重定向、供应商固定 HTTPS 地址。
SQLite secure_delete、物理删除；尚无静态加密，生产需加密卷与密钥托管。单线程原型仍需反向代理限流、身份与 HTTPS。不应直接暴露 wsgiref 给公网。
数据导出由用户选择保存位置，含个人信息；不要提交或公开。删除全部数据会清空当前数据库；已导出文件、云备份与平台日志由部署者额外删除。不是承诺无法从底层存储恢复。

自选背景只保存在应用数据目录，不上传服务器。没有访问用户 Windows/D 盘、Ollama、MCP、私人浏览器或私人账号。开发环境与 CI 完全云端，GitHub hosted runners，不使用 self-hosted。

敏感检测关键词规则有限；应保持聊天保存关闭、最小化长期记忆。真实模型调用会将本轮输入和相关已同意记忆发送给供应商，必须先知晓其数据政策。预算上限是调用次数，不是精确金额；部署者须设置供应商支出限额。
官方角色素材、商标、背景和声音仅使用有权使用的内容；不要冒充官方，不做未经许可的声线克隆。语音提供商接入前审核数据保留规则。
