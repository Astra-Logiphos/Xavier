# 模块六验收：饮食记录

1. 打开“热量追踪”→“饮食”，搜索“米饭”。无需启动后端；预期显示数据库结果及每 100 克千卡。
2. 选热量非空的一项，输入 150 克→记录，当日摄入增加该食物热量×1.5。
3. 切换“份”，填写每份克数与份数，按实际摄入重量计算。
4. 手动添加“我的测试食物”，每 100 克 200 千卡，记录 50 克，增加 100 千卡。
5. 重启 App 后记录与自定义食物保留；删除记录后汇总更新。
6. 设置→填写体重与基础代谢：70 kg、1500 千卡、活动系数 1.2。首页目标为 1800，目标缺口为 1800−今日净热量。
