# UI 与可选外观

视觉方向：星夜低饱和紫蓝 / 月光浅青 / 暖春浅粉；圆角卡片、宽屏侧栏、手机横向导航、明确连接状态；不捆绑受版权保护角色图。
已有外观入口：主题选择、自选图片、40%–98% 遮罩、0–32 圆角、0.85–1.4 字号。主题设置通过 SharedPreferences 持久化。背景复制到应用支持目录，不上传后端；移除时删除应用副本。
主题参数可以导出 appearance.json，不含背景设备路径；导入通过参数表单。以后增加背景库、气泡样式、主题包、字体和节日主题，可扩展 Appearance 模型与同一外观页面。当前不支持执行任意主题代码、CSS、插件或自定义布局，不是完整 UI 构建器。

常用新增/编辑已改为逐字段表单，列表每行一条、开关/类型使用选择器，不需要用户写 JSON。后续扩展审核筛选、完整证据面板和冲突比较，增加无障碍/屏幕阅读器/键盘操作测试。
Flutter 源码没有经过渲染或真实设备验证，颜色与断点属于设计意图，不能声称视觉验收通过。
