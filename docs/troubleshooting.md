# 排错

| 现象 | 操作 |
|---|---|
| 没有下载包 | 先查看是否存在实际 Release。未连接仓库/未推 tag/缺签名/构建失败都不会有产物 |
| 401 | 客户端 AUTH_TOKEN 与后端不一致；它不是模型 Key |
| 503 token 未配置 | 在本机环境注入 AUTH_TOKEN，不写进客户端源代码 |
| HTTP/网络失败 | 客户端只允许本机 http://127.0.0.1:8080；先启动 bat，检查健康接口和令牌文件 |
| API 默认关闭 | 继续使用 mock；启用真实模型需服务端变量与本轮确认 |
| ALLOW_PAID_API 拦截 | 免费配额未验证，默认防费用；开启可能产生费用，需要预算 |
| 没有学习回忆 | 未同意保存、未学过该主题、记录已删、低置信度；不会补造 |
| 没有每日完整历史 | 本地启动器默认保存；设置关闭后无法生成新历史。不要记录的轮次不会出现在总结 |
| canon 审核失败 | 核对来源已批准、source_type=official、HTTPS URL、source_version，无冲突 |
| blocked 版本 | 查看回归报告；修改候选约束后重新审核；不跳过门禁 |
| 来源点击后无导入文本 | URL 只创建待审核来源，不执行抓取。需要手动提供必要授权摘录 |
| 语音按钮无音频 | 当前 mock，无录音/合成，避免误以为服务失效 |
| 背景变更无效 | 文件损坏/格式不支持/超过 10 MB；选择 PNG/JPEG，尝试移除再选 |
| Android 构建失败 | 看 Actions 日志、签名 Secrets、SDK runner 模板；不要切 debug 签名冒充正式包 |
| Windows 无法启动 | 完整解压 ZIP，保留 DLL/data。干净 Windows 验证和 VC runtime 安装提示待 CI 实机确认 |
| CI 分析错误 | 此环境未执行 Flutter，按 pinned SDK 修正 analyzer 报错，再发布；不要忽略错误发布 |

日志不会保存完整正文。报告问题只提供脱敏状态、错误码和构建日志，不上传真实数据库或聊天。
