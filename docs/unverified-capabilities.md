# 能力状态与验收边界

2026-10-13，本项目为个人本地 Windows 应用，源码提交至 PR #2；前两批预览发布 companion-preview-22-1 / 23-1。九模块清单见 acceptance-matrix.md，逐项验收见 module-1-acceptance.md 至 module-9-acceptance.md。

| 能力 | 状态 |
|---|---|
| 本地后端与持久化 | 便携 Python、BAT、SQLite、令牌复用、登录自启、崩溃恢复在托管Windows实测通过 |
| 人设与字体 | 用户报告静态人设、问候/打卡/提醒、人设介绍、四种字体；模板预留，未做真实模型语义评测 |
| Windows主题/图库 | 十主题与本地图库实现，压缩、持久化、静态/隐藏暂停测试及页面截图自检 |
| 食品与运动数据 | 指定食品OCR源1838条，226条缺失或异常热量置空；2024运动镜像1111条，非完整1144条；保留来源与哈希 |
| 热量与目标 | get_storage每日保存，实际克数/小时公式、体重、BMR×活动系数、缺口、历史趋势；数字是记录与估算，不冒充测量 |
| 提醒与通知 | 五类本地通知及Windows计划任务补排已实现，原生Windows门禁全部通过；不声称你的电脑已收到横幅 |
| 全量备份/恢复 | 后端SQLite事务导入、客户端热量/设置/背景字节恢复均测试；令牌/模型Key不导出 |
| Flutter环境 | 当前实例已安装Flutter3.35.7，analyze零问题，最新23项Flutter测试通过；后端62项本机61通过、Windows专属1跳过 |
| Android完整版本 | 按用户要求后置；源代码包含通知权限和开机重排配置，当前改造版本未做完整Android构建/实机验收 |
| 真实模型/STT/TTS/搜索 | 未接真实服务；模型调用、计费和外部搜索未验证或授权。自动来源搜索不擅自启动 |
| 角色审核与记忆 | 人工审核、显式同意与候选门禁保留；自动语义冲突、专业检索/论文解析未实现 |
| 签名/安装包 | Windows ZIP预览，未提供生产代码签名；完整解压即可用，无需安装Flutter/Python |
| 用户设备验收 | 没有访问用户私人电脑；指南用于确认显示、通知及设备兼容性 |

数据库和JSON备份未静态加密，请按自己的Windows账户与本机目录管理。手动备份不会随应用数据删除。额度中断后无法自行五小时唤醒，恢复时依据 PROJECT_STATE.md 优先继续本仓库。
