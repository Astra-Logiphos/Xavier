# Android 免费规则预览

下载 xinghui-android-preview.apk，主动允许浏览器安装来源后安装。打开即可进入免费规则体验，去“聊天”输入文字，去“外观”换主题和自己的背景。无需填 API Key。

这不是通用大模型或正式生产版。没有配置云端后端时，聊天与打卡只在本次打开有效，不会伪称已建立长期记忆。长期记忆、来源审核、相处学习规则和真实模型需要连接你自己的云端后端；模型 Key 只在服务端配置。

这是 Flutter debug 开发预览，使用临时开发签名，包名带 .preview；与未来正式版分开。后续预览若签名不同可能无法覆盖安装，需要卸载旧预览；主题/背景等本地配置也可能被清除。不能把开发签名当正式签名。生产 APK/AAB 仍需仓库所有者提供稳定签名 Secrets。

GitHub Actions 已编译不等于真机测试通过；此环境没有 Android 真机。语音为 mock。APK 不包含后端数据库、聊天、模型权重或供应商 Key。
