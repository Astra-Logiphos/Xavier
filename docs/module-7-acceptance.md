# 模块七验收：运动与热量历史

1. 设置→填写体重与基础代谢，输入 70 kg / 1500 千卡 / 1.2。重启后保留，目标显示 1800。
2. 热量追踪→运动→有氧→搜索“慢跑”→选择“慢跑 · 自选配速”（2024 代码 12020，MET 7.5）→30 分钟→记录。预期消耗 262.5 千卡（7.5×70×0.5）。这是估算，体重变动不改写旧记录。
3. 饮食添加 200 千卡后，同页与首页净值为 −62.5，目标缺口 1862.5。实际已有记录时按当日全部记录累加。
4. 四类可浏览/搜索，点击查看更多运动展开后续结果；每条保留原始 MET 与描述。
5. 展开“周 / 月趋势与历史”，切换 7 / 30 天；上方日历可查看以前日期，趋势条与明细均对应各日记录。点击某日回看。
6. 重启后记录保留，删除一条后摄入/消耗/净值自动更新。
