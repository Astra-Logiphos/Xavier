# 模块八验收：本地提醒

1. 设置→每日提醒：学习/情绪/陪伴/饮食/运动各有独立开关与时间。开启一项并选时间，预期设置保存；Windows 任务计划程序出现当前用户的 XinghuiReminderRefresh（每日 00:05 和登录补排），无管理员权限或远程服务。
2. 点击“一分钟测试提醒”，保持设备醒着、允许星辉通知、关闭系统勿扰。等待一分钟，预期 Windows 通知中心收到“星辉 · 陪伴”，正文来自人设静态台词库。关闭应用也应由 Windows 已排入的原生队列触发。
3. 退出重开，五项开关/时间保留。设定另一类一分钟后的日常时间验证互相独立。
4. 关闭全部五项，预期待排通知取消、补排任务注销；临时一分钟测试可再次独立使用。
5. Windows 构建有原生冒烟证明 notification-smoke.json：确认定时项入队并在到点后被系统消费。这个证明不替代你的屏幕通知横幅验收。

使用 flutter_local_notifications。Windows 不提供原生每日重复，预排八个自然日并由本地计划任务每日补排；每日程序不显示应用窗口。Android 已补通知权限、开机重排接收器与 desugaring 配置，使用系统允许的非精确定时；完整 Android 编译与实机验收按要求后置。设备睡眠、勿扰、系统禁用通知影响显示；开启失败时设置明确显示原因。
