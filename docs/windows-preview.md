# Windows 桌面预览

下载 xinghui-windows.zip，完整解压，双击 xinghui_companion.exe。DLL、data 和运行库文件必须与 exe 保持在一起；包内有使用说明。
不需要安装 Flutter 或 Python 来使用免费规则聊天和主题/背景设置。

未连接后端时是免费规则体验，不是通用模型。聊天与打卡仅当前打开有效，不伪称长期记忆。
要使用长期记忆、人设审核、学习记录和相处规则，需要部署云端后端并在设置中填写 HTTPS 地址与 AUTH_TOKEN。模型 Key 只能在服务端 Secret 注入，真实 API 可能收费。

已进行 GitHub 托管 Windows 编译、Flutter 测试、运行库完整性检查与 10 秒进程启动检查。没有访问用户电脑，也没有用户设备 UI 验收。本版是未代码签名的 x64 便携预览，不是正式安装包。
官方人设语料为空；语音模拟；平台自动搜索仍未授权。详见仓库验收和未验证清单。
