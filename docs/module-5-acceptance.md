# 模块五验收：背景与图库

1. 外观 → 背景图库，依次选择十个主题；缩略图显示名称，当前主题显示勾选。截图检查渐变及对应主装饰。
2. 星星、星辰花、花瓣/杨桃、流星/光弧、光尘独立开关及数量、速度、透明度、大小可调；主题只使用一个主动画，少量配景按主题配置。
3. 打开跟随时间自动切换：晨雾 → 星辰花语 → 星夜长河。关闭动态背景后画面静止；窗口隐藏时动画停止。
4. 从相册导入 → 拖动裁剪 → 使用这张。照片压缩为 JPEG，长边不超过 1920、质量 80，保存应用文档目录并生成缩略图。
5. 遮罩从 0 到 60% 可调。选中照片、关闭重开 App，设置保留；长按照片删除，只删应用副本，不删原照片。

按用户确认，Windows 使用 image_picker + 本地裁剪界面 + Dart image 压缩，替代不支持 Windows 的两款插件。
