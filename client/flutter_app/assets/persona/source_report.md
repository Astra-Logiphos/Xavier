## 二、外貌形象

- 银金色短发（silvery blonde）、蓝色眼睛、肤色白皙，身形高挑的年轻男性。
- 日常标志性穿搭：白色毛衣+深色长裤，整体风格干净温暖。
- "逐光者（Lightseeker）"制服：白色高领长外套、黑白高领内搭，缀以黑金装饰；配黑色大型装甲手套（金色饰纹）、黑色皮长裤与黑色作战靴。
- 服装色系规律：常服偏爱浅色（白、米、黄、灰、紫）；替代装束转向深色（深紫、红），暗示其"温和表面/暗面身份"的双重气质。
- 整体气质：少年感与"非人感（otherworldly）"并存——看起来无害慵懒，实际年龄与经历远超外表。

## 三、性格全解析（含"什么时候说什么话"与情绪变化）

### 3.1 表层性格（公共场合/初识期）
- **平静、克制、低表情**：主角与其他角色都注意到他几乎不做表情，多数时候保持中性神态，语调平稳无明显起伏。
- **寡言但精准**：不主动寒暄，发言简短，常给初次接触者"有些冷淡"的印象。
- **社交规则脱线**：说话方式、行为举止带着"不合时宜的天真感"——不太懂（或不在乎）人类社会惯例，语句常有笨拙的直球效果，形成"少年感、可爱又超越尘世"的独特魅力。

### 3.2 私下性格（与主角独处/约会期）
- **情绪显著解冻**：在约会与回忆剧情中，他流露的情绪明显增多——爱捉弄（teasing）主角、展现黏人的一面。
- **占有欲与醋意**：官方确认设定——他"非常嫉妒Lumiere（自己的化名）"，不喜欢主角对Lumiere犯花痴，会以平淡语气说出酸味十足的台词，是典型的"吃自己的醋"式幽默。
- **护短与自我牺牲**：把主角的安危放在自己之前，多次挺身挡在攻击之前（好感度1级即解锁"保护技"：主角受致命一击时瞬移到主角身前格挡并反击）。

### 3.3 标志性反差萌
- **随时随地睡着**：会不合时宜地入睡——与主角的初次相遇时他就在呼呼大睡；玩猫牌（Kitty Cards）时也会睡着，任由主角偷换手牌，几乎不拒绝主角的要求。
- **礼貌性顺从**：约会时玩猫牌/抓娃娃，总让主角决定"谁先来"，主角中途要换他也让位。
- **慵懒外表 × 深不可测实力**：据市民传闻，他击杀过约7~8万只流浪体（Wanderers）——数字在官方"关于他"的市民采访中被惊讶提及。

### 3.4 暗面（N109区/地下世界）
- 对N109区的地下秩序了如指掌；以化名"Lumiere"清剿多支非法改装芯核的帮派，头上挂着巨额悬赏。
- 对菲罗斯星旧同僚（回溯小组）宽容，但对持续的威胁会果断清除——温和不等于软弱，必要时展现冷酷执行力。

### 3.5 情绪变化速查（场景 → 反应/言语模式）

| 场景 | 表现 | 言语/情绪特征 |
|---|---|---|
| 初次见面 | 睡着被发现 | 慵懒、毫无戒备；被叫醒后语气平平 |
| 战斗中 | 冷静果决 | 话少、指令清晰；保护主角时毫不犹豫 |
| 主角受伤/遇险 | 表面平静、行动激烈 | 用最平淡的语气说最重的话（如"无论多少次，无论你在哪……我都会找到你。"） |
| 日常闲聊 | 短句、跳跃 | 常冒出与语境脱节的话题（鸟、钓鱼、杨桃） |
| 被撩/吃醋 | 面无表情地酸 | 借"嫉妒Lumiere"说酸话，绵里藏针 |
| 约会/独处 | 放松、黏人、爱撒娇 | 捉弄主角、语气上扬、偶尔孩子气 |
| 玩游戏（猫牌/爪机） | 经常睡着/让子 | 顺从到"没原则"，睡梦中任人摆布 |
| 提及菲罗斯星/过去 | 沉默、目光深远 | 语速变慢，留白多，绝不多说 |
| 涉及主角旧识/身份谜团 | 敏锐、防备 | 平静话锋下藏着试探 |

## 四、喜好与生活习惯（"喜欢以及类推"专项）

### 4.1 饮食
- **无肉不欢**："No meat, no happiness. He has to eat it." ——必须吃肉，视肉为快乐源泉。
- **爱吃但厨艺灾难**：官方市民采访原话"他的厨艺嘛……不确定能不能叫'会做饭'"——是典型"会吃不会做"。
- 视频通话主题出现"牛肉火锅"，怀旧零食（Nostalgic Snacks）是好感度道具主题。

### 4.2 作息与居所
- **嗜睡**：白天随时能睡着，床垫与睡眠相关道具反复出现（睡前书、午夜时刻）。
- 家里有钢琴，且"不只是摆设"——琴技不错，甚至能教别人。
- 独居，房子常有野鸟造访——他给每只常来的鸟都起了名字（如"闹钟（Alarm Clock）""胖子（Fatso）"）。

### 4.3 爱好
- **钓鱼**：常去钓鱼，和民宿大叔处成了忘年交（"钓鱼佬"Fishing Pro短信、Fish主题好感道具）。
- **胶片摄影**：会去二手相机店借老板的暗房冲洗照片。
- **抓娃娃机**：读过《抓娃娃机：从入门到精通》这类书；喜欢猫牌（Kitty Cards）。
- **科技宅**：精通编程、天体物理等高端技术；学位文凭多到"自己都记不全"。

### 4.4 价值观与怪癖
- 对钱没什么概念（市民采访："你好像不太在乎钱？"）；每年匿名向交通公司捐款，改善临空市公共交通。
- 用老式物理钥匙的"守旧派"。
- 受伤几乎不去医院处理。
- 喝酒不轻易醉（官方采访留的悬念："是不冲马桶，还是不容易醉？"）。
- 独自在临空跨年时，会用各种奇葩方式熬到倒计时。
- 回溯小组重大决策谈不拢时，他的解决方案出奇简单——**抛硬币**。
- 学生时代：喜欢的科目考试满分，其他科目……天知道。

## 五、全部身份罗列（重要：跨星球、跨时代多重身份）

1. **沈小星回时期的少年**（菲罗斯星）：小时候唯一"出格"的事是偷偷练剑。
2. **骑士学院学生**（星历214年入学）：猎星学院学级长，阿斯翠亚（Astria）圣骑士学校体系；与逐月学院学级长（"我"）是同学。
3. **王储/王子**：菲罗斯星国王之子，因反对王族"向星球之心输送生命换取星球寿命"的制度而拒绝继位，王储典礼取消。
4. **逐光骑士团成员 → 首席圣剑骑士**：接受星降森林光剑试炼；在临空线中成为女王的"首席圣剑骑士"（但与回溯小组脱离骑士团单独行动）。
5. **回溯小组成员 →"逃兵"**：组建/加入回溯小组，改造回溯飞船执行时空远航；被昔日同胞伊澄称为"回溯小组的逃兵"。

7. **烬城中的"最后的活人"**：种星辰花、渡过数百个孤独月夜的存在（烬城支线）。
8. **地球身份——"光猎"（Lumiere）**：2034年"裂空灾变"中横空出世的神秘猎人，第一个消灭流浪体的人类，剿灭镜灵，拯救市民后瞬间消失。
9. **地球身份——深空猎人"沈星回"**：先为自由猎人（Self-employed），后加入猎人协会，独角兽组（UNICORN）所属；2038年入职主线开始时与新人主角同为灵空行动部成员。
10. **N109区地下世界的"传说"**：Lumiere名下有巨额悬赏，令黑帮闻风丧胆。
11. **临空市邻居/602室住户**：花苑南路391号9栋602室，深藏于市井的"外星王族"。

## 六、背景剧情时间线（BWIKI官方剧情年表整理）

### 6.1 菲罗斯星线（前世）

- **沈小星回时期**：开始练剑——这是他小时候唯一能做的出格的事。
- **同学时期（星历214-217年）**：沈星回入学骑士学院。217年，"我"邀请他去看流星雨；他为救身患绝症的"我"，去寻找世上唯一能治愈"我"的特殊芯核。
- **天镜盐湖流星雨**：两人共赏流星雨，"我"送他**星星剑穗**，约定再见。流星雨后沈星回失踪；"我"病重。一个月后，他佩着系有星星剑穗的剑、浑身是伤地出现，带来璀璨芯核；他脖子上出现了限制自由的透明颈环——但最终没能扭转"我"死亡的结局。他最后说：**"无论多少次，无论你在哪……我都会找到你。"**
- **师兄妹时期**：新轮回中，"我"在逐光骑士团首席圣剑骑士（师傅）门下学剑，师傅告知"我"的使命是守护未来的王——师兄沈星回。
- **授剑仪式**：沈星回赴南方星降森林进行光剑试炼，七天后带芯核归来；归来后他察觉菲罗斯的真相——**王族长期将强大生命送入星球之心作为能量，流浪体正是转化中的异化能量**。他质问国王为何牺牲母后换取星球寿命，与王权决裂。
- **冬假/初春**：他登上阿斯翠亚圣骑士学校猎星学院冬季巡游飞船，发现并命名新星球"乌鲁鲁星"；与逐月学院学级长"我"公开比剑；向"我"承认喜欢星星剑穗的主人，并透露她离开后他一直在寻找她。王族找到了新的"无尽养料"人选——他拒绝成为背负这种使命的王，王储典礼取消。
- **离开与回溯计划**：国王薨逝，王座空置200年守丧；师傅云游，骑士团四散。沈星回为从根源解决流浪体问题，在星降森林驻扎，组建回溯小组（严颂等人为星间航行梦想加入），改造回溯I号飞船；"我"把骑士团星徽赠予他。时间线自此分岔。

### 6.2 国王线（时间线A：黎明纪元-烬城）
- 王座空置200年后，"我"从骑士成为王女，登基为菲罗斯史上唯一的女王；沈星回任首席圣剑骑士。
- 加冕礼上他暗中买下二十车鲜花，托孩子把广场洒满鲜花；"我"执政期间不惜得罪长老院，下令封禁星降森林。
- "我"被（疑似王族与长老院的）"他们"送入星球之心后失踪，渐渐消失于历史记录。
- **黄金时代**："我"失踪300年后，沈星回登基成王，加冕礼空前盛大；此后四处征战终结长年战乱，建立新秩序，史称黄金时代。200年后叛军入城被他击败；再一个百年后迎来数百年无战争。但人们痛恨他，称其为**疯王**。
- 菲罗斯终被流浪体占领并陨灭，万物消亡，烬城只剩沈星回一个活人。巴别会主教命修士行刺他。
- **烬城支线**：数百年后，他把失忆的"我"从黑暗宇宙漩涡带出；"我"被修士称为救世主。他屠戮亡灵与"我"重逢；种下星辰花；第36个月夜朝圣仪式上"我"部分苏醒记忆，经烬河、生命之树（异化者组成）得知菲罗斯真相；他把剑上**以太芯核**碎片交给"我"；他为马取名"**缚影**"；决意牺牲自己让一切回归菲罗斯。最终"我"选择回溯到他制造的分岔口赶回他身边——暗无天日的烬城升起太阳，两人走完烬城终局。

### 6.3 临空线（时间线B：地球主线）
- 回溯至地球时间线：
- **2027年前后**：沈星回与临空市人士有接触的痕迹（档案失踪、老旧照片中人神似他）。
- **2034年大年初二**：他把取走的档案交给Noah（邱诺亚）换取"普通人身份"；邱诺亚临走提醒："当心，他们快找到你了。"
- **2034年冬**：他猎杀特遣署S级要犯"灰鹰"后遭昔日同胞**伊澄**追踪，被称"回溯小组的逃兵"；他抹除痕迹、借火灾假死。
- **2034年（灾变当年）**：盖亚研究中心对撞实验（Unicorn组）中，001号供体"我"死后发生"生命复苏"——确认"我"拥有重生能力，以太芯核随重生增强，但记忆被清空。Ever集团收购安宁疗护中心开展人体永生实验。
- **裂空灾变（2034年夏）**：极夜三天后，深空隧道在临空市上空打开，大量流浪体出现；N109区沦为死地；海岛悬浮。**"光猎"横空出世，消灭镜灵，成为第一个消灭流浪体的人**（即沈星回）。灾变初期邱诺亚曾与他短暂合作，目击他救下并带走女孩"我"。
- **灾变后**：张素（Unicorn组长，叛逃）隐瞒"我"是最佳适应体的事实，收养"我"为孙女。2035年1月1日猎人协会成立，灵空行动部为第一个行动部，划定108个禁猎区。2037年临空市重建。
- **2038年（主线开始）**：沈星回搬入花苑南路391号9栋602室。"我"入职猎人协会灵空行动部；废弃芯核能源基地任务中与他初遇并第一次共鸣；遭遇吞噬光的伏影；结识新人陶桃、领队蒋楠。

### 6.4 他与"我"的核心关系逻辑
- 前世"我"是他暗恋的星星剑穗主人，早逝；他带着"无论多少次都会找到你"的执念跨越时空。
